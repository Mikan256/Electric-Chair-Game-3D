# 水曜日のダウンタウン「電気イスゲーム」のルール

『水曜日のダウンタウン』の「電気イスゲーム」は、1〜12番の12脚の椅子を使い、相手がどの椅子に電流を仕掛けたかを読み合う2人対戦の心理戦ゲームです。

単純な運試しではなく、相手の思考を読んだり、会話で選択を誘導したりする駆け引きが重要になります。

## 1. 基本ルール

- プレイヤー：2人
- 椅子：1〜12番の計12脚
- それぞれが交互に「電流を仕掛ける側」と「椅子に座る側」になる。
- 目標は相手より多くのポイントを獲得すること。

## 2. 1ターンの進行

1ターンは次のように進みます。

### ① 電流を仕掛ける

攻撃側は、12脚の中から1脚を選び、電流を仕掛けます。

### ② 椅子を選択する

守備側は、電流が仕掛けられている椅子を予想しながら、座る椅子を選択します。

### ③ 電流を実行する

攻撃側が電流を作動させます。

### ④ 結果判定

- 電流を回避した場合：選んだ椅子の番号と同じポイントを獲得。
- 電流を受けた場合：それまでの獲得ポイントがすべて0点になる。

### ⑤ 椅子の処理

ポイントを獲得した椅子は、そのゲーム中は使用できなくなります。

その後、攻守を交代して次のターンに進みます。

## 3. 勝敗条件

| 条件 | 結果 |
|---|---|
| 40ポイント先取 | 勝利 |
| 相手に3回感電させる | 勝利 |
| 最大8ターン終了 | 規定回数終了時にポイントが多いプレイヤーが勝利 |

## 4. 重要なルール上のポイント

| 状況 | 処理 |
|---|---|
| 12番の椅子で成功 | 12ポイント獲得 |
| 1番の椅子で成功 | 1ポイント獲得 |
| 電流を受ける | 累積ポイント全没収 |
| 得点済みの椅子 | 再使用不可 |
| 電流を受けた椅子 | 再使用可能 |

※電流を受けた椅子は残り、得点を獲得した椅子だけが使用できなくなります。

## 5. このゲームの面白いところ

このゲームの本質は、次の3つの心理戦です。

- **高得点狙い**：12番などの高得点を狙うと、相手に狙われる可能性も高くなる。
- **行動の読み合い**：相手が自分の選択をどう予測しているかを考える。
- **会話による心理戦**：相手の発言や態度から仕掛けた椅子を推測する。

例えば、相手が「12番は危ないですよ」と言ってきた場合、それが本当に12番に仕掛けたことを隠すためなのか、逆に12番を安全だと思わせるためなのか、という読み合いが生まれます。
